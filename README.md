# Hi, I'm Phoenix

I'm a husband, an Army veteran, and a computer science student at Ozarks Technical Community College.

I've always been fascinated by computers and the idea that I could write a program and make it do whatever I wanted. I originally started school pursuing IT, but after taking my first introduction to programming course, I found that I enjoyed the problem-solving side of programming far more than I expected.

The more I learned about how programs actually work, the more I wanted to understand what was happening behind the scenes.

I'm currently focusing on **C# and ASP.NET**, with **SQL** as part of my coursework. I also have experience with **HTML, CSS, JavaScript, Vue, and Bootstrap**. I'm particularly drawn to backend development because I enjoy working on the logic and problem-solving that happens behind the interface.

## What I'm Building

My biggest personal project right now is an **ARK: Survival Evolved / ARK: Survival Ascended breeding companion**.

The goal is to build an application that allows players to enter information about their dinosaurs and use that information to help optimize their breeding process.

More importantly, this project is giving me a chance to take what I'm learning and put it together into something of my own. I plan to build, develop, and eventually ship the application using **HTML, CSS, C#, ASP.NET, and SQL**.

The project is still in its early stages, but I'm intentionally building it as a long-term project. As I work on it, I'm continually running into new problems to solve and new concepts I need to learn.

That's one of the things I enjoy most about programming: sometimes the project tells you what you need to learn next.

## Where I'm Heading

I'm still learning, and that's something I want this GitHub to reflect. I'm interested in understanding *why* things work rather than simply getting them to work, and I try to write code that is readable, maintainable, and understandable to someone other than myself.

One of the areas I'm increasingly interested in is **cybersecurity**, and I plan to pursue a minor in cybersecurity alongside my bachelor's degree. My current goal is to become a **backend developer with a strong foundation in cybersecurity**, although I'm keeping an open mind about eventually moving into full-stack development.

I believe becoming a good programmer means being willing to continually learn, listening to other people's perspectives, and writing code that isn't just functional, but readable and maintainable.

I'm still developing as a programmer, but I have a direction I'm excited about—and a lot more I want to learn.
